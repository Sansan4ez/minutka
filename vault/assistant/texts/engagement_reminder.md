# Автоматическое напоминание об участии

Этот файл — источник единственного текста мягкого напоминания. Он один для всех участников: приложение отправляет его дословно, без подстановок и без участия LLM. Отправку выполняет ежедневная системная проверка по метке `lagging`; процедура — [runbook напоминаний](../../../docs/runbooks/participant-engagement-reminders.md).

Текст обязан заранее называть следующие ярусы эскалации и не должен содержать давление, стыд, сравнение с другими участниками, оценку продуктивности или предположение о причинах отсутствия.

<!-- minutka-engagement-reminder:start -->
Здравствуйте! Мягко напоминаю о «Минутке»: если сегодня удобно, просто напишите пару слов о последнем рабочем дне — без оценки и обязательной формы. Если касаний не будет, с вами может связаться методолог программы; при длительном отсутствии методолог может сообщить руководителю компании только факт участия или отсутствия участия, без содержания переписки.
