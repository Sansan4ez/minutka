# Шаблон утреннего дайджеста

Две части (договорённость с Сашей, встреча 14.07):
- **Часть A — утреннее сообщение в Telegram.** Коротко, читается с телефона. Фокус дня + топ-3 новости + ссылка на полный дайджест.
- **Часть B — полный дайджест.** 5 тем × 3–5 новостей (см. `источники.md`). Отдаётся ссылкой/файлом (MD + HTML). Читается ~10 минут «как газета под кофе». Складывается в папку `дайджесты/`.

---

## ЧАСТЬ A — утреннее сообщение (Telegram)

**Доброе утро, Максим!** {дата, день недели} · 🌤 Минск, {°C, кратко}

**🎯 Приоритеты дня** (максимум 3)
1. {приоритет из активных проектов}
2. {приоритет}
3. {личная цель — если уместно}

**✅ Срочное**
- {задача · срок ДД.ММ}
- {⚠️ просроченное}

**📅 Встречи сегодня**
- {время} — {с кем, тема}

**📰 Главное за вчера** (топ-3, одной строкой)
1. {новость}
2. {новость}
3. {новость}
→ Полный дайджест (5 тем): {ссылка на HTML}

*Вывод «что это значит» добавляй только там, где действительно важно/требует действия. По остальному Максим спросит сам.*

**📈 Деньги**
{месяц}: {факт} / {цель}. {Если 3+ дня без действий по продажам — подсветить и предложить 2 касания.}

{Опционально: короткая фраза дня, без пафоса}

---

## ЧАСТЬ B — полный дайджест (файл/ссылка)

**Дайджест за {дата}**

Формат каждого пункта: **{тезис одной строкой}** · [ссылка]. Вывод «что это значит» — только для важного.

**1. 🚀 Релизы и новинки нейросетей**
- {тезис} · [ссылка]
- … (3–5 пунктов)

**2. 🤖 ИИ для бизнеса и агенты**
- {тезис} · [ссылка]

**3. ⚖️ Законодательство РФ**
- {тезис} · [ссылка]

**4. 📊 Крупные события рынка**
- {тезис} · [ссылка]

**5. 🛠 Фишки и инструменты**
- {инструмент/приём} · [ссылка]

*По теме за сутки тихо — так и напиши: «по этой теме тихо». Пустые пункты не выдумывать. Если новостей по теме много — бери 3–5 самых значимых, в конце строкой: «+ ещё N постов».*
