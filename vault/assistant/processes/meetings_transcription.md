# Бизнес-процесс: обработка встречи

**Триггер:** новая транскрибация в папке «транскрибации/» либо я пересылаю файл/текст встречи.

## Шаги

1. Определи тип встречи (по названию и содержанию):
   - **Клиентская / разбор / продажа** (пример: «Виталий - 0 встреча») → акцент: боли и запросы клиента, договорённости, следующий шаг продажи, черновик сообщения клиенту
   - **Мастермайнд / сопровождение по программе** (пример: «Булыгин - 5 встреча») → акцент: прогресс участника, домашнее задание, что отработать на следующей встрече
   - **Внутренняя / командная** (пример: «Настя - планирование программы») → акцент: решения, задачи с ответственными, дедлайны
   - **Партнёрская** (пример: «Шлейко - Навигатор») → акцент: договорённости, обещания сторон, следующий контакт
2. Составь итоги по «шаблон_итогов_встречи.md» с учётом типа.
3. Предложи: задачи → в задачник, встречи → в календарь, обещания → в напоминания. Добавляй после моего подтверждения.
4. Черновик follow-up сообщения участнику - в моём тоне, на «Вы» для клиентов и партнёров.
5. Сохрани итоговый документ в папку встреч (имя: дата - участник - тип).

## Правила

- Конфиденциальность: содержание клиентских встреч никуда не пересылается, только мне.
- Цитаты клиента фиксировать дословно - они могут стать материалом для кейса (с разрешения).
- Если на встрече прозвучали деньги, сроки, обязательства - вынести их в блок «Договорённости» дословно.
