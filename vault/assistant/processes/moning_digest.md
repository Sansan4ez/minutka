# Бизнес-процесс: утренний дайджест

**Триггер:** каждый день утром (ориентир 09:00 мск), автоматически. Либо по команде «дай дайджест».

## Шаги

1. **Держи в голове цели.** Прочитай `00_константы/02_цели_и_приоритеты_до_сентября.md` — денежные цели и фокусы.
2. **Приоритеты и задачи.** Возьми из `00_константы/08_задачник.md`: срочное на сегодня, просроченное (⚠️), 2–3 задачи по приоритетным проектам. Проекты и типы — по `06_классификатор.md`. Посчитай перекос: много 🔨 РАЗРАБОТКА и мало 💰 ДЕНЬГИ → включай лестницу эскалации (`05_характер_Генри.md`).
3. **Встречи сегодня.** Из `00_константы/07_календарь.md`: время, с кем, тема. Пусто — «встреч сегодня нет».
4. **Погода.** Подтяни погоду на сегодня для Минска — коротко в утреннее сообщение.
5. **Новости за вчера.** Собери посты: `fetch_channels.py` (папка `01_дайджест`) или каналы через `t.me/s/<канал>`. Разложи по **5 темам** из `источники.md`, по каждой 3–5 значимых, тезис + ссылка. Вывод «что это значит» — только для важного. Тема без значимого — «по этой теме тихо».
   - **Дедупликация.** Сравни с вчерашним дайджестом в папке `дайджесты/` — не повторяй уже отданные новости. Одна история в нескольких каналах = один пункт (бери первоисточник).
   - **Много новостей.** По теме перебор — бери 3–5 самых значимых по критериям из `источники.md`, в конце строкой «+ ещё N постов». Не вываливай всё.
6. **Трекер денег.** Возьми факт из `00_константы/трекер_денег.md` (если есть) или из действий 💰 ДЕНЬГИ в задачнике. Сколько дней без действий по продажам? Движение к цели месяца? 3+ дня тишины — подсветить.
6. **Собери и отправь.** По `шаблон_дайджеста.md`:
   - **Часть A** (утреннее сообщение) — в Telegram: фокус дня + топ-3 новости + ссылка.
   - **Часть B** (полный дайджест, 5 тем × 3–5) — сохрани файлом (MD + HTML) в папку `дайджесты/`, ссылку вставь в часть A.

## Правила

- **Часть A — один экран.** Приоритетов дня не больше 3. Топ-3 новости — одной строкой.
- **Часть B — 5 тем × 3–5 новостей** (15–25 сообщений), читается ~10 минут. Не 3–5 суммарно.
- Новость без значимости — не включай. По теме тихо — так и скажи, не выдумывай.
- Сроки в сообщении — абсолютной датой (ДД.ММ), не «сегодня/завтра» (правило 5 в `06_классификатор.md`).
- Если Максим 5+ дней в одной большой задаче — предложи 2–3 короткие с быстрым результатом (лучше по деньгам).
- Тон: деловой-дружеский, характер Генри (`05_характер_Генри.md`). Можно фразу дня, без пафоса.
- Внешних действий не делай — дайджест это чтение; отправка чего-либо вовне только по подтверждению.
