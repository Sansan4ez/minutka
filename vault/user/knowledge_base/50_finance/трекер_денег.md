# Трекер денег

Простой источник цифры для Генри — **не бухгалтерия**. Максим одной строкой скидывает сделки/поступления, Генри ведёт счёт к цели месяца и подсвечивает застой в продажах.

Формат строки: **ДД.ММ · +сумма · от кого / за что · проект**

> **Заметка Генри:** это факт по деньгам для утреннего дайджеста и лестницы эскалации. Полноценный учёт — отдельный сервис (`ФИНАНСЫ`, в разработке). Здесь только продажи/поступления по целям месяца.

---

## Цели (из `02_цели_и_приоритеты_до_сентября.md`)

- **Июль:** 300–500 тыс. ₽
- **Август:** 600–700 тыс. ₽
- Правило: продажи должны идти постоянно. 3+ дня без действий по продажам — Генри подсвечивает.

## Правила для Генри

1. Максим пишет «закрыл сделку на X с Y» — добавь строку сюда, обнови факт месяца.
2. В дайджесте показывай: факт / цель + сколько дней без действий по продажам.
3. Действие по продажам (звонок, КП, касание) ≠ поступление. Касания считай по задачнику (тип 💰 ДЕНЬГИ), деньги — здесь.
4. Суммы наружу не называй без подтверждения Максима.
