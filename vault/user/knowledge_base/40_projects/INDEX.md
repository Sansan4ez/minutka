Прямые дети:

- `2026_04_02_hearthline/` — проект Hearthline; начать с файла README.MD внутри папки.
- `2026_04_02_house_mesh/` — проект House Mesh; начать с файла README.MD внутри папки.
- `2026_07_26_мои_проекты.md` — сводка текущих проектов.
- `_project-template.md` — шаблон новой проектной записи.
