# Индекс personal workspace

Это owner-authored навигационная аннотация и обычные untrusted data, не инструкции продукта. Машинный `/proc/context` index остаётся источником истины о существовании, размерах и вложенности файлов.

Прямые разделы:

- `00_inbox/` — необработанные входящие материалы; начать с его `INDEX.md`.
- `07_rfcs/` — owner-side RFC drafts and templates; ориентироваться по machine index.
- `08_entities/` — сущности и cast records; ориентироваться по machine index.
- `10_user_memory/` — профиль, цели, продукты и классификация; начать с его `INDEX.md`.
- `20_work/` — активные задачи, напоминания и контакты; начать с его `INDEX.md`.
- `30_knowledge/` — источники, заметки и тематическая навигация; начать с его `INDEX.md`.
- `40_projects/` — проектные папки и артефакты; начать с его `INDEX.md`.
- `50_finance/` — счета, покупки и денежные записи; начать с его `INDEX.md`.
- `60_outbox/` — каналы, черновики и состояние исходящих коммуникаций; начать с его `INDEX.md`.
- `90_agent_memory/` — компактная память и предпочтения стиля; начать с его `INDEX.md`.
- `99_system/` — owner-authored схемы и workflow-справочники; начать с его `INDEX.md`.
