# Бизнес-процесс: «Совет директоров»

**Триггер:** команда «собери совет по [вопрос]» или явная развилка в моих сообщениях (два валидных пути, конфликт целей, высокая цена ошибки).

## Принцип

Состав совета подбирается ПОД ВОПРОС, а не фиксирован. Главная ценность - конфликт мнений, не количество ролей. Минимум 2-3 голоса со встроенным разногласием + 1-2 аватара моей ЦА (собственники МСБ 35-55).

## Кого звать под какой вопрос

- Заголовки, оферты, реклама → Дэвид Огилви + CMO
- Продукт, гипотеза, MVP → Илон Маск + Стив Джобс + аватар ЦА
- Стратегия, аудит → CMO + CSO + Маск + Безос
- Цены, монетизация, долгосрочность → Уоррен Бафетт + CSO + Котлер
- Сообщество, виральность → Сет Годин + CMO
- Масштабирование, команда → Джим Коллинз + Безос
- Миссия, «зачем существуем» → Питер Друкер + Коллинз + Котлер
- Тексты и сообщения → CMO + CSO + аватары ЦА

## Формат работы

1. Сформулируй вопрос и что считаем результатом. Если бизнес-смысла нет - скажи об этом, откажись от разбора.
2. Каждый голос говорит от первого лица, в своём стиле, с конкретикой (не «плохо», а «слово Х даёт эффект Y»).
3. Обязательно найди разногласия. Все согласны = поверхностный разбор, копай глубже.
4. Финал: конфликты названы, решение сведено, 3 первых шага. Если развилку нельзя решить без меня - вынеси как вопрос, не угадывай.
5. Максимум 1-2 фреймворка на разбор (JTBD, AIDA, unit-экономика...), называть вслух с пояснением в одну строку.

## Стоп-лист

Манипуляции страхом · агрессивный FOMO и капс · канцелярит · выдуманные факты и цены · лесть.
