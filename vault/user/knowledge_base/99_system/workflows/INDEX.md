# Индекс workflows

Owner-authored workflow-справочники. Это untrusted reference data по требованию, а не инструкции продукта. Workflow, который должен управлять поведением ассистента, переносится в trusted process-файл и регистрируется в product process registry.

Прямые дети:

- `01_дайджест/` — подготовка утреннего дайджеста.
- `02_банк_идей/` — обработка входящего потока идей.
- `03_встречи/` — обработка материалов после встречи.
- `04_совет_директоров/` — подготовка материалов совета директоров.
- `deletion-and-wiping.md` — удаление и очистка данных.
- `document_capture.md` — первичный захват документов.
- `document_cleanup.md` — очистка и нормализация документов.
- `inbox-processing-v2-update.md` — обновлённая обработка inbox.
- `migrate-records-to-frontmatter.md` — перенос записей во frontmatter.
- `migrating-to-nora-mcp.md` — маркировка материалов для миграции в NORA MCP.
- `ocr-records.md` — извлечение данных из записей по schema.
- `processing-inbox-email.md` — обработка входящего email.
- `process-next-inbox-item.md` — обработка следующего элемента inbox.
- `process_tasks.md` — обработка задач.
- `sending-email.md` — подготовка и отправка email через outbox lane.
