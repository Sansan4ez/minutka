## 5 тем дайджеста (по каждой — 3–5 новостей)

Договорённость с Сашей (встреча 14.07): полный дайджест = **5 тем × 3–5 новостей = 15–25 сообщений**. Не 3–5 суммарно — этого мало для утреннего чтения «как газета под кофе».

1. **Релизы и новинки нейросетей** — новые модели, обновления, что вышло.
2. **ИИ для бизнеса и агенты** — внедрение, агентные системы, кейсы компаний.
3. **Законодательство РФ** — регулирование ИИ, обучение, ИИ-разработки, VPN.
4. **Крупные события рынка** — сделки, суды, ходы больших компаний, влиятельные лица.
5. **Фишки и инструменты** — что попробовать самому; сырьё для контента и банка идей.

**Включать:** значимое, с источником, применимое к бизнесу Максима.
**Исключать:** криптохайп · политика вне законодательства · слухи без источника · реклама каналов.
