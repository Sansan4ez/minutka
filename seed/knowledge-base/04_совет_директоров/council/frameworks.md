# Каталог фреймворков для совета директоров

> Полный справочник для скилла `/council`. Базовые 20+ моделей описаны в [SKILL.md](SKILL.md).
> Сюда обращаться только когда базовых недостаточно — задача редкая или требует специфической методологии.
>
> Каждый фреймворк: **что это**, **для чего**, **типичный пример применения**.

## 1. Маркетинг (16)

### 5 сил Портера (Porter's Five Forces)
**Для чего:** анализ конкурентного поля.
**Состав:** угроза новых конкурентов, угроза заменителей, влияние поставщиков, влияние покупателей, уровень конкуренции внутри отрасли.
**Пример:** оценка привлекательности входа в новую нишу.

### Buyer Persona
**Для чего:** создание профилей идеальных клиентов.
**Суть:** обобщённые, основанные на реальных данных образы сегментов ЦА. Помогают понять мотивацию, боли, желания, поведение для персонализированных стратегий.
**Пример:** «Buyer Persona для B2C-сегмента магазина тканей».

### AARRR (Pirate Metrics)
**Для чего:** построение продуктовой воронки.
**Состав:** Acquisition (привлечение) → Activation (активация) → Retention (удержание) → Referral (рекомендации) → Revenue (доход).
**Пример:** воронка онлайн-курса по нейросетям.

### Kotler 4P Marketing Mix
**Для чего:** формирование маркетинговой стратегии.
**Состав:** Product / Price / Place / Promotion.
**Пример:** маркетинговая стратегия нового продукта.

### STP (Segmentation / Targeting / Positioning)
**Для чего:** разработка маркетинговой стратегии.
**Суть:** сегментация рынка → выбор привлекательных сегментов → уникальное позиционирование бренда.
**Пример:** маркетинговая стратегия строительной компании.

### SWOT
**Для чего:** общий анализ компании.
**Состав:** сильные/слабые стороны (внутреннее), возможности/угрозы (внешнее).
**Пример:** стратегия развития обувной фабрики.

### 4C Marketing Mix
**Для чего:** анализ клиентоориентированности (альтернатива 4P).
**Состав:** Customer (потребности), Cost (полная стоимость для клиента), Convenience (удобство), Communication (взаимодействие).
**Пример:** анализ сети ресторанов на клиентоориентированность.

### RACE Planning Framework
**Для чего:** структура цифрового маркетинга.
**Состав:** Reach (охват) → Act (действие) → Convert (конверсия) → Engage (удержание).
**Пример:** анализ digital-стратегии онлайн-школы.

### The Hook Model (Nir Eyal)
**Для чего:** создание продуктов, формирующих привычку.
**Состав:** Trigger (стимул) → Action (простое действие) → Variable Reward (переменная награда) → Investment (вложение пользователя).
**Пример:** создание затягивающей серии книг или приложения.

### JTBD (Jobs To Be Done)
**Для чего:** глубинный анализ мотивов покупки.
**Суть:** не «кто клиент», а **какую работу он нанимает наш продукт сделать**. Смотрит на мотивацию на уровне «зачем», а не «кто».
**Пример:** JTBD-анализ кухонного комбайна.

### Customer Journey Map
**Для чего:** стратегия взаимодействия с клиентом на разных этапах его пути.
**Суть:** визуализация пути клиента от первого контакта до постпродажного обслуживания. Выявляет точки улучшения опыта.
**Пример:** карта пути клиента для кофейни.

### Brand Pyramid
**Для чего:** построение узнаваемости бренда.
**Состав снизу вверх:** осведомлённость → атрибуты → выгоды → ценности → лояльность.
**Пример:** стратегия развития узнаваемости бренда эксперта.

### SOSTAC
**Для чего:** комплексное маркетинговое планирование.
**Состав:** Situation → Objectives → Strategy → Tactics → Action → Control.
**Пример:** маркетинговая стратегия магазина зоотоваров.

### Kano Model
**Для чего:** анализ удовлетворённости клиентов.
**Категории:** базовые (обязательные), производные (линейные), восхищающие (приятно удивляют, повышают лояльность).
**Пример:** анализ удовлетворённости клиентов зубной пастой.

### BCG Brand Resonance Pyramid
**Для чего:** построение глубокой связи бренд↔потребитель.
**Уровни:** осведомлённость → производные ассоциации → реакция потребителей → глубокая связь.
**Пример:** бренд-стратегия нового стирального порошка.

### Brand Asset Valuator (BAV)
**Для чего:** оценка бренда.
**Факторы:** дифференциация, актуальность, престиж, знание бренда.
**Пример:** оценка существующего бренда по 4 параметрам.

## 2. Развитие бизнеса (16)

### PEST-анализ
**Для чего:** анализ внешней макросреды.
**Состав:** Political / Economic / Social / Technological. Часто расширяют до PESTLE (+ Legal + Environmental).
**Пример:** PEST-анализ рынка недвижимости в Москве.

### Business Model Canvas (BMC)
**Для чего:** построение/визуализация бизнес-модели.
**9 блоков:** ценностные предложения, клиентские сегменты, каналы, отношения с клиентами, потоки доходов, ресурсы, действия, партнёры, структура издержек.
**Пример:** бизнес-модель салона флористики.

### BSC (Balanced Scorecard)
**Для чего:** измерение достижения целей компании.
**4 перспективы:** финансы, клиенты, внутренние процессы, обучение и развитие.
**Пример:** система метрик для центра косметологии.

### VRIO Framework
**Для чего:** анализ конкурентных преимуществ ресурсов компании.
**Критерии:** Value (ценность), Rarity (редкость), Imitability (сложность копирования), Organization (организация).
**Пример:** анализ преимуществ издательства.

### OKR (Objectives and Key Results)
**Для чего:** постановка целей с измеримыми ключевыми результатами.
**Суть:** Objective — куда идём (качественно), Key Results — как поймём что дошли (количественно, 3-5 шт).
**Пример:** OKR для повышения прибыли компании.

### Porter's Value Chain
**Для чего:** повышение эффективности процессов компании.
**Суть:** анализ основных и вспомогательных действий, создающих ценность для конечного продукта.
**Пример:** оптимизация процессов на основе анализа цепочки ценности.

### McKinsey 7S Framework
**Для чего:** анализ организационной согласованности.
**7 элементов:** Strategy, Structure, Systems, Style, Staff, Skills, Shared Values.
**Пример:** диагностика готовности компании к стратегическим изменениям.

### RACI (Responsible / Accountable / Consulted / Informed)
**Для чего:** распределение ролей в проектах.
**Суть:** для каждой задачи назначается: кто исполняет, кто отвечает за результат, с кем консультируются, кого информируют.
**Пример:** матрица ролей для проекта запуска продукта.

### Ansoff Matrix
**Для чего:** стратегии роста.
**4 стратегии:** проникновение на рынок, разработка продукта, развитие рынка, диверсификация.
**Пример:** выбор стратегии роста для существующего бизнеса.

### CAGE Distance Framework
**Для чего:** выход на новые рынки.
**4 типа «расстояний»:** Cultural / Administrative / Geographic / Economic.
**Пример:** вывод бизнеса из России на рынок ОАЭ.

### Theory of Constraints (Голдратт)
**Для чего:** выявление «узких мест» в бизнес-процессах.
**Суть:** система ограничена самым слабым звеном. Найти его → расшить → найти следующее.
**Пример:** аудит сети стоматологий на «узкие места».

### BCG Matrix (Бостонская матрица)
**Для чего:** оценка продуктового портфеля.
**4 квадранта:** Звёзды (высокий рост + высокая доля), Дойные коровы (низкий рост + высокая доля), Вопросительные знаки (высокий рост + низкая доля), Собаки (низкое и то и другое).
**Пример:** распределение инвестиций между продуктами компании.

### McKinsey Growth Pyramid
**Для чего:** определение стратегии роста.
**3 уровня:** оборона текущих позиций → инвестиции в текущие направления → новые продукты/инновации.
**Пример:** пути роста книжного магазина.

### PDCA Cycle (Plan-Do-Check-Act)
**Для чего:** непрерывное улучшение процессов.
**Цикл Деминга:** планируй → делай → проверяй → корректируй и повторяй.
**Пример:** стратегическая сессия для фитнес-клуба.

### ADKAR Change Management
**Для чего:** управление изменениями.
**5 шагов:** Awareness (осознание необходимости) → Desire (желание участвовать) → Knowledge (знание как меняться) → Ability (способность) → Reinforcement (закрепление).
**Пример:** стратегия внедрения изменений в телеком-компании.

### Hoshin Kanri
**Для чего:** реализация долгосрочных целей (3-5 лет).
**Суть:** синхронизация целей компании на всех уровнях, от долгосрочных до ежедневных задач.
**Пример:** стратегическое планирование на 5 лет.

## 3. Онлайн-образование (16)

### ADDIE
**Для чего:** разработка структуры обучающего курса.
**Этапы:** Analysis → Design → Development → Implementation → Evaluation.
**Пример:** курс по экстремальному вождению.

### 4C/ID (Four Component Instructional Design)
**Для чего:** методология для сложных курсов с акцентом на формирование навыков.
**4 компонента:** учебные задачи, поддерживающая информация, процедурная информация, частичная практика.
**Пример:** онлайн-курс по флористике.

### Bloom's Taxonomy
**Для чего:** разработка целей обучения.
**Уровни:** знание → понимание → применение → анализ → синтез → оценка.
**Пример:** цели курса digital-маркетолог.

### Gagne's Nine Events of Instruction
**Для чего:** детальная разработка курса.
**9 шагов:** привлечение внимания → сообщение цели → стимуляция предыдущих знаний → подача нового материала → руководство → практика → обратная связь → оценка → закрепление.
**Пример:** структура каждого урока курса.

### Kirkpatrick's Four Levels of Evaluation
**Для чего:** оценка эффективности обучения.
**4 уровня:** Reaction (удовлетворённость) → Learning (усвоение) → Behavior (изменение поведения) → Results (влияние на бизнес).
**Пример:** оценка эффективности курса «Reels-профессионал».

### Backward Design
**Для чего:** разработка курса от результатов к контенту.
**Суть:** сначала определяют конечные результаты и цели, затем методы оценки, в конце создают контент.
**Пример:** структура курса «Гештальт-психология».

### ARCS Model
**Для чего:** повышение мотивации к прохождению курса.
**Состав:** Attention (внимание) → Relevance (релевантность) → Confidence (уверенность в успехе) → Satisfaction (удовлетворение).
**Пример:** повышение доходимости курса.

### Merrill's Principles of Instruction
**Для чего:** максимально практичные курсы.
**5 принципов:** ориентация на задачу, активное обучение, демонстрация, применение, интеграция.
**Пример:** курс «Специалист по антиквариату».

### TPACK (Technological Pedagogical Content Knowledge)
**Для чего:** интеграция технологий в образование.
**3 компонента:** педагогические методики + знания содержания + технологии.
**Пример:** курс «Подготовка к ЕГЭ по математике».

### Community of Inquiry (CoI)
**Для чего:** концепция курса, построенного на community-модели.
**3 присутствия:** когнитивное (критическое мышление) + социальное (общение) + педагогическое (направление).
**Пример:** курс «AI/ML-разработчик».

### Action Mapping
**Для чего:** курсы, ориентированные на практическое внедрение навыков.
**Суть:** проектирование от действий, которые должен делать ученик, а не от тем для изучения.
**Пример:** курс по слиппингу с обязательным внедрением.

### Competency-Based Learning (CBL)
**Для чего:** курс, ориентированный на овладение навыками.
**Суть:** ученик продвигается по мере освоения навыков, не по календарю.
**Пример:** курс «SMM в Telegram».

### MOOC Framework
**Для чего:** массовые открытые онлайн-курсы.
**Особенности:** большие группы, свободный доступ, масштабируемая оценка (автопроверка, форумы, пиринг).
**Пример:** курс безопасности для 500+ учеников.

### VARK (Visual / Auditory / Reading-Writing / Kinesthetic)
**Для чего:** мультисенсорное обучение.
**Суть:** разные стили восприятия — давать материал в разных форматах.
**Пример:** программа обучения микологии.

### Experiential Learning (Kolb's Cycle)
**Для чего:** обучение через опыт.
**4 этапа:** конкретный опыт → наблюдение и рефлексия → формирование абстрактных концепций → активное экспериментирование.
**Пример:** обучение управлению яхтой.

### Heutagogy
**Для чего:** самообучение.
**Суть:** ученик сам берёт ответственность за обучение, выбирает материалы и методы, развивает критическое мышление и саморефлексию.
**Пример:** программа изучения макросов в Excel.

## 4. Продажи (16)

### SPIN
**Для чего:** универсальная модель продаж через вопросы.
**Состав:** Situation → Problem → Implication → Need-Payoff.
**Пример:** скрипт продажи услуг барбершопа.

### 7-Step Sales Process
**Для чего:** классическая модель продаж.
**7 шагов:** подготовка → установление контакта → выявление потребностей → презентация → работа с возражениями → закрытие → послепродажное обслуживание.
**Пример:** стратегия продаж пластиковых окон.

### BANT
**Для чего:** квалификация лидов.
**Критерии:** Budget / Authority / Need / Timing.
**Пример:** квалификация входящих заявок.

### MEDDIC
**Для чего:** сложные B2B-продажи с длинным циклом.
**Состав:** Metrics → Economic buyer → Decision criteria → Decision process → Identify pain → Champion.
**Пример:** стратегия продажи решения IT-интегратору.

### SNAP Selling
**Для чего:** продажа перегруженным информацией покупателям.
**Принципы:** Simple → iNvaluable → Aligned → Priority.
**Пример:** продажа услуг финансового консультанта.

### Solution Selling
**Для чего:** продажа через предложение решения, не продукта.
**Суть:** выявляем проблему → продаём решение → товар вторичен.
**Пример:** стратегия продаж книги-руководства.

### The Challenger Sale
**Для чего:** продажа через обучение клиента.
**Суть:** продавец «вызывает» клиента, помогая увидеть новые потребности и возможности.
**Пример:** стратегия продаж дизайнера интерьеров.

### Sandler Selling System
**Для чего:** продажи через диагностику.
**Суть:** продавец как консультант, помогает клиенту самому осознать скрытые мотивы и желания.
**Пример:** скрипт диагностики для тренера по скорочтению.

### NEAT Selling
**Для чего:** B2B-продажи.
**Состав:** Need → Economic impact → Access to Authority → Timeline.
**Пример:** стратегия продажи логистических услуг крупному ритейлеру.

### Pain-Gain Selling
**Для чего:** простая модель продаж.
**Суть:** боль, которую решает продукт + выгоды от покупки.
**Пример:** стратегия продаж магазина футболок.

### Feel-Felt-Found
**Для чего:** отработка возражений.
**Скрипт:** «I know how you feel → Others have felt the same → But they found that...»
**Пример:** отработка возражений в B2B.

### SCOTSMAN
**Для чего:** квалификация лидов в B2B.
**Состав:** Solution / Competition / Originality / Timeframe / Size / Money / Authority / Need.
**Пример:** квалификация заявок IT-интегратора.

### GPCTBA/C&I
**Для чего:** скрипт продаж на основе квалификации.
**Состав:** Goals / Plans / Challenges / Timeline / Budget / Authority / Consequences & Implications.
**Пример:** скрипт продаж услуг индивидуального пошива.

### LAER (Listen / Acknowledge / Explore / Respond)
**Для чего:** активный диалог с клиентом.
**Суть:** активное слушание + признание проблемы + исследование причин + ответ.
**Пример:** стратегия продаж услуг автосервиса.

### SOCIAL (Speed / Organization / Clarity / Information / Accommodations / Listening)
**Для чего:** продажи с быстрым реагированием.
**Пример:** стратегия продаж квартир в новостройке.

### Hunt / Gather / Cultivate / Harvest (HGCH)
**Для чего:** комплексная модель полного цикла.
**Стадии:** поиск клиентов → сбор информации → развитие отношений → закрытие сделки.
**Пример:** стратегия продаж офисной мебели.

## 5. Копирайтинг (16)

### AIDA
**Для чего:** универсальная воронка любого текста.
**Состав:** Attention → Interest → Desire → Action.
**Пример:** текст о важности подсчёта БЖУ.

### PAS (Problem / Agitate / Solution)
**Для чего:** продажа через решение проблемы.
**Суть:** обозначить проблему → усилить эмоциональное восприятие → предложить решение.
**Пример:** продающий пост в Telegram о курсе.

### 4P (Picture / Promise / Prove / Push)
**Для чего:** продажа через яркий образ будущего.
**Структура:** яркая картина → обещание → доказательства → призыв к действию.
**Пример:** таргетированное объявление услуг финансового аналитика.

### QUEST (Qualify / Understand / Educate / Stimulate / Transition)
**Для чего:** максимально кастомизированные тексты под сегмент.
**Пример:** email-рассылка о фитнесе для пенсионеров.

### FAB (Features / Advantages / Benefits)
**Для чего:** продуктовые посты.
**Структура:** характеристики → преимущества → выгоды для клиента.
**Пример:** пост о доставке рационов питания.

### Before-After-Bridge
**Для чего:** продающие тексты со сторителлингом.
**Структура:** текущее состояние клиента → желаемое → мост (решение).
**Пример:** услуги SMM-агентства.

### The 4U (Urgency / Usefulness / Uniqueness / Ultra-specificity)
**Для чего:** заголовки и оферты.
**Пример:** текст лендинга услуг автоподбора.

### SLAP (Stop / Look / Act / Purchase)
**Для чего:** каскадные продающие тексты.
**Пример:** реклама велосипедов в социальных сетях.

### The "So What?" Test
**Для чего:** тест ключевых тезисов текста.
**Суть:** после каждого тезиса задаём «И что?» — если ответа нет, тезис не работает.
**Пример:** проверка готового лендинга.

### Star-Story-Solution
**Для чего:** продающие истории.
**Структура:** яркий персонаж → история → решение.
**Пример:** история диетолога.

### The Rule of Three
**Для чего:** сильная структура любого текста.
**Суть:** три ключевых элемента/идеи — устойчиво запоминается, мозг любит триплеты.
**Пример:** структура статьи об рынке торговли древесиной.

### OATH (Oblivious / Apathetic / Thinking / Hurting)
**Для чего:** определение состояния аудитории для текста.
**Уровни боли:** не осознают проблему → безразличны → думают о ней → активно ищут решение. Под каждый уровень — свой подход.
**Пример:** текст премиум ювелирного салона.

### The 5 Basic Objections
**Для чего:** тексты, снимающие основные возражения.
**5 возражений:** No time / No need / No trust / No money / No hurry.
**Пример:** текст онлайн-курса по родительству.

### TEA (Theory / Example / Application)
**Для чего:** экспертные тексты.
**Структура:** теория → пример → практическое применение.
**Пример:** статья о тренде edutainment.

### Пирамида Минто
**Для чего:** любые аналитические тексты.
**Суть:** сначала главный тезис → аргументы → факты-примеры. Структура «обратной пирамиды».
**Пример:** статья о калистенике.

### FOREST (Fact / Opinion / Reason / Example / Summary / Transition)
**Для чего:** большие продающие тексты.
**Структура:** факт → мнение → причина → пример → резюме → переход к следующей теме.
**Пример:** лендинг корейской косметики.

## 6. Современные модели (13)

> Добавлены 2026-05-15 по результатам расширения совета. Это методологии, которые часто используются в современных стартапах, продуктовых командах и копирайтинге, но не вошли в классические 5 категорий выше.

### Lean Startup (Eric Ries)
**Для чего:** запуск продуктов через быстрые гипотезы.
**Суть:** Build → Measure → Learn. MVP вместо «идеального продукта», pivot если данные не подтверждают гипотезу.
**Пример:** запуск SaaS, тестирование новой ниши.

### Customer Development (Steve Blank)
**Для чего:** валидация идеи через выход к клиенту.
**4 этапа:** Customer Discovery → Customer Validation → Customer Creation → Company Building.
**Принцип:** «Get out of the building» — не сидите в офисе, идите к клиентам.
**Пример:** перед запуском продукта — 50 интервью с потенциальными клиентами.

### Lean Canvas (Ash Maurya)
**Для чего:** упрощённый Business Model Canvas под стартапы.
**9 блоков на одну страницу:** Problem / Solution / Key Metrics / Unique Value Proposition / Unfair Advantage / Channels / Customer Segments / Cost Structure / Revenue Streams.
**Отличие от BMC:** заменены блоки «Key Partners/Activities/Resources» на «Problem/Solution/Key Metrics/Unfair Advantage» — фокус на проблеме клиента.
**Пример:** валидация идеи нового продукта за час.

### Crossing the Chasm (Geoffrey Moore)
**Для чего:** переход продукта от early adopters к mass market.
**Суть:** между ранними адоптерами (которым новинка интересна сама по себе) и ранним большинством (которым нужна практичность и социальное доказательство) — пропасть. Многие продукты в ней умирают.
**Пример:** стратегия выхода технологичного продукта на массовый рынок.

### Blue Ocean Strategy
**Для чего:** создание новых рынков вместо борьбы в существующих.
**Суть:** красные океаны — известные рынки с жёсткой конкуренцией. Голубые — новые, где конкуренции нет. Инструмент: ERRC Grid (Eliminate / Reduce / Raise / Create).
**Пример:** Cirque du Soleil — не «лучший цирк», а смесь цирка и театра, отдельная категория.

### Product-Led Growth (PLG)
**Для чего:** рост через сам продукт (вместо рекламы / продаж).
**Суть:** продукт сам приводит, активирует и удерживает клиентов. Freemium, viral loops, self-serve onboarding. Примеры: Slack, Notion, Figma.
**Пример:** стратегия роста SaaS через бесплатный план с виральными механиками.

### Jobs Stories (Intercom)
**Для чего:** расширение JTBD под конкретные ситуации.
**Формат:** «Когда [ситуация], я хочу [мотивация], чтобы [результат]».
**Отличие от User Stories:** убирает «as a user» (нет про роли) и фокусируется на контексте, не на пользователе.
**Пример:** «Когда я открываю приложение в метро, я хочу читать офлайн, чтобы не зависеть от связи».

### Pirate Funnel (Dave McClure)
**Для чего:** расширенная версия AARRR с конкретными метриками.
**5 этапов:** Acquisition (CAC, channel mix) → Activation (% реально начавших использовать) → Retention (DAU/MAU, churn) → Revenue (ARPU, LTV) → Referral (K-factor).
**Пример:** дашборд продуктовой воронки SaaS-продукта.

### Five Whys (Toyota)
**Для чего:** поиск корневой причины проблемы.
**Суть:** задать «почему?» 5 раз подряд, доходя до корневой причины вместо симптомов.
**Пример:** «Конверсия упала» → «почему?» → «больше отказов на странице оплаты» → «почему?» → «новая капча» → «почему её добавили?» → «жалобы на спам» → «почему спам пошёл?» → «не закрыли OAuth-уязвимость». Реальная причина — безопасность, не дизайн страницы.

### System 1 / System 2 (Daniel Kahneman)
**Для чего:** понимание как клиент принимает решение.
**Суть:** System 1 — быстрое, автоматическое, эмоциональное. System 2 — медленное, аналитическое, осознанное. Реклама и оферты в основном работают через System 1, B2B-решения чаще через System 2.
**Пример:** для импульсной покупки — эмоция и якорь (System 1). Для дорогой подписки — факты и логика (System 2).

### BJ Fogg Behavior Model (B = MAT)
**Для чего:** проектирование действия пользователя.
**Формула:** Behavior = Motivation × Ability × Trigger. Если действие не происходит — одна из трёх составляющих слабая.
**Пример:** если триал не активируют — мотивация низкая (зачем им?), способность плохая (сложно настроить?) или триггер не сработал (не увидел кнопку)?

### Golden Circle (Simon Sinek)
**Для чего:** позиционирование бренда через «зачем».
**3 уровня:** Why (зачем существует компания) → How (как делаем) → What (что делаем). Большинство компаний коммуницируют наизнанку (What → How → Why), сильные бренды — изнутри наружу (Why → How → What).
**Пример:** «Мы продаём компьютеры» (What) vs «Мы бросаем вызов статус-кво, делаем красивые простые продукты, и у нас есть компьютеры» (Why-first, стиль Apple).

### StoryBrand (Donald Miller)
**Для чего:** структура продающего сообщения через сторителлинг.
**7 элементов:** Character (клиент-герой) → has a Problem → meets a Guide (бренд-проводник, не герой) → who gives them a Plan → calls them to Action → Success (что будет если согласится) → Failure (что будет если откажется).
**Ключевая идея:** **клиент — герой истории, бренд — проводник** (Гэндальф, не Фродо). Большинство брендов делают себя героями — это ошибка.
**Пример:** структура лендинга. Не «мы лучшие на рынке» (бренд-герой), а «у вас X-проблема, мы поможем её решить за 3 шага» (клиент-герой).
