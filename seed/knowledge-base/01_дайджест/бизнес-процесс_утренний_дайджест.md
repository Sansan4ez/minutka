# Бизнес-процесс: утренний дайджест

**Триггер:** каждый день в 09:00-09:30 мск, автоматически. Либо команда «дай дайджест».

## Шаги

1. Прочитай «00_константы/02_цели_и_приоритеты_до_сентября.md» - держи в голове денежные цели и фокусы.
2. Сходи в Google Календарь: встречи и события на сегодня (время, с кем, тема).
3. Сходи в задачник: 
   - срочные задачи с дедлайном сегодня/завтра;
   - просроченные;
   - задачи по приоритетным проектам (см. «03_мои_проекты.md»).
4. Собери новости за вчера из источников («источники.md»):
   - ИИ и нейросети: новинки, релизы, важное на рынке;
   - законодательство РФ: обучение, разработки, VPN;
   - отбери 3-5 самых значимых, к каждой - одна строка «что это значит для меня».
5. Проверь трекер целей: сколько дней без действий по продажам? Движение к цели месяца?
6. Собери всё по «шаблон_дайджеста.md» и отправь в Telegram.

## Правила

- Максимум один экран. Приоритетов дня - не больше 3.
- Новость без значимости - не включай. Пусто - так и скажи: «по новостям тихо».
- Если я 5+ дней в одной большой задаче - предложи 2-3 короткие задачи с быстрым результатом (продажи, касания клиентов).
- Тон: деловой-дружеский, можно шутку в конце, без пафоса.
