# Product Part: Methodologist Web Panel

> **Статус: historical.** Диаграмма описывает legacy-концепцию «Минутки» и не является архитектурой пилота. Веб-панель методолога — не-цель пилота; справочники, участие и выгрузки обслуживаются через SQL/CLI по [RFC §7](../../architecture/rfc-minutka-tenancy-and-reporting.md#7-не-цели-и-когда-пересмотреть).

## Purpose

`Methodologist Web Panel` — отдельная браузерная поверхность для оператора программы. Методолог через неё запускает двухнедельный поток для компании, управляет списком участников, видит операционные статусы вовлечённости, отправляет мягкие напоминания и готовит клиентскую карту автоматизации из безопасных агрегированных данных. Панель должна воплощать privacy boundary: она не показывает индивидуальные транскрипты, личные задачи, личные портреты или индивидуальные эмоциональные состояния сотрудников.

## Assumptions / Open Questions

- `Methodologist Web Panel` включает reporting и подготовку клиентской карты автоматизации, потому что пользователь подтвердил, что `Reporting and Automation Map Generation` не является отдельным Product Part.
- Панель работает только с операционными статусами и безопасными агрегатами из `Data Storage and Privacy Layer`; она не получает индивидуальные разговоры, конкретные задачи, личные портреты или индивидуальные эмоциональные состояния.
- Статусы `lagging` и `dropped off` основаны на активности участия, а не на содержании сообщений или оценке эффективности сотрудника.
- Мягкие напоминания инициируются из панели, но доставляются через `Telegram Bot Shell`; точный транспорт между частями не фиксируется на этом уровне.
- Клиентское руководство не получает отдельный доступ к панели на текущем уровне модели; оно получает подготовленную методологом карту автоматизации как итоговый документ.
- Персональные недельные и финальные итоги сотрудника агрегируются из `Data Storage and Privacy Layer` и показываются сотруднику через `Telegram Bot Shell`; методологическая панель не владеет личным отчётом сотрудника как индивидуальным просмотром.
- Панель не рассчитывает privacy-sensitive агрегаты сама: она отображает только безопасные данные и статусы, подготовленные через `Data Storage and Privacy Layer`.
- Для methodologist/client аналитики действует правило минимальной группы: срезы меньше 5 человек не показываются, чтобы не деанонимизировать сотрудника.
