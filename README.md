# Минутка

«Минутка» — сервис диагностики рабочих рутин сотрудников (Telegram-first). Сотрудник каждый день коротко отмечает, чем занят и что мешает; из этих касаний собирается его профиль, а для компании — обезличенный отчёт и карта кандидатов на автоматизацию.

Рабочий **прототип** с осознанной ставкой на лёгкую, простую и потому надёжную архитектуру. Построен на [Mastra](https://mastra.ai) + TypeScript.

## Происхождение репозитория

Это **клон репозитория персонального ассистента** (`git@github.com:Sansan4ez/personal-assistant.git`, доступен как remote `assistant`), сделанный по [RFC линейки из трёх продуктов](docs/architecture/rfc-three-products-implementation.md) §2.2. Продукты дальше расходятся: у «Минутки» собственные БД, сервер, Telegram-бот, секреты и трекер. Критичные фиксы общего фундамента (безопасность, потеря данных) переносятся между репозиториями cherry-pick'ом — общая история для этого сохранена.

Клон получает готовыми транспорты Telegram/HTTP/CLI, invite/consent/onboarding/profile-контур, chat-runtime с agent-led routing, извлечение insights, процессы утра и вечера, executable specs без сети. Основная новая работа — мультитенантная ось и обезличенная отчётность.

## Архитектура в двух словах

Поток: `Telegram / HTTP / CLI → AssistantService → typed use-cases → stores`.

Агент сам роутит по процессам в один ход (agent-led routing), но **не пишет в хранилища напрямую и не выполняет внешних действий без подтверждения** — всё идёт через типизированные use-cases. База знаний хранится файлами (Markdown) в S3/MinIO, без эмбеддингов и векторной БД: файловая навигация проще, прозрачнее в трейсах и дешевле.

Подробнее — в [`AGENTS.md`](AGENTS.md). Целевая архитектура «Минутки» — [RFC мультитенантного контура и обезличенной отчётности](docs/architecture/rfc-minutka-tenancy-and-reporting.md); унаследованный рантайм — [RFC архитектуры ассистента](docs/architecture/rfc-personal-assistant-architecture.md) и [agent-led routing](docs/architecture/rfc-agent-led-routing.md).

## Privacy by Design

Приватность — свойство конструкции хранилища, а не настройка, которую можно забыть включить. Это особенно важно, потому что агент — это LLM, и заинжектить её может даже содержимое самого хранилища.

- **Три стороны с разной видимостью.** Сотрудник видит все свои данные; методолог — только обезличенные записи и агрегаты; компания — только агрегаты, прошедшие правило ≥5 (§2.3–2.4 RFC «Минутки»).
- **Обезличенный след пишется рядом с личной записью** (dual-write в одной транзакции) и не содержит `user_id`, свободного текста и точных timestamps — читателей с cross-owner-правами в рантайме нет вообще.
- **Изоляция по владельцу — структурная.** Каждый документ жёстко привязан к владельцу схемой ключей хранилища, а идентификатор владельца задаётся приложением и никогда не принимается из аргументов инструмента. Выйти за пределы своего пространства нельзя в принципе, а не «если правильно настроен фильтр».
- **Журнал без содержимого.** В аудит попадают только факты операций (тип, число результатов, признак усечения, исход) — никогда текст документов или запросов.
- **Надёжная запись.** Изменения атомарны и версионируемы: параллельные операции не затирают друг друга и не теряются.

## Команды

```bash
npm run typecheck      # tsc --noEmit
npm run specs          # executable specs (без сети)
npm run verify         # typecheck + specs
npm run db:migrate     # применить миграции
npm run telegram:dev   # локальный Telegram-бот (polling)
```

## Структура

- [`src/`](src) — код по слоям: `domain/`, `contracts/`, `application/`, `mastra/`, `infrastructure/`, транспорты (`server/`, `telegram/`, `client/`).
- [`vault/`](vault) — Agent Vault: роль агента, навыки-процессы, типизированные действия.
- [`docs/`](docs) — архитектура, конвенции, планы, продуктовый бриф, runbooks.
- [`specs/`](specs) — executable specs, гоняются без LLM/сети через in-memory адаптеры.
- [`migrations/`](migrations) — SQL-миграции PostgreSQL.
- [`nixos/`](nixos) — деплой-стек, унаследованный от ассистента как **шаблон**: секреты и хост не переиспользуются, стек перенастраивается под собственный сервер «Минутки» до первого деплоя.
